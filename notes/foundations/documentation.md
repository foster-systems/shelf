sources:
  - title: "Diátaxis"
    author: Daniele Procida
    url: "https://diataxis.fr/"
    type: framework
    year: 2026
    note: "A framework for planning and writing technical documentation. It sorts docs into four kinds by what the reader needs: tutorials, how-to guides, reference and explanation, and gives the purpose and style of each. Procida first presented an earlier version of it at Divio."
  - title: "Documentation"
    author: Tom Manshreck
    url: "https://abseil.io/resources/swe-book/html/ch10.html"
    type: guide
    year: 2020
    note: "A chapter of Software Engineering at Google on how Google treats documentation like code, with owners, source control, review and bug tracking. It covers writing for a known audience, giving each document one type and purpose, and keeping docs fresh or deprecating them."
  - title: "Documentation quality"
    author: DORA
    url: "https://dora.dev/capabilities/documentation-quality/"
    type: guide
    year: 2022
    note: "DORA's page on internal documentation as a capability, from the 2022 State of DevOps research. It measures quality with eight survey items on attributes such as clarity, findability and reliability, and reports that teams with above-average documentation get a much larger lift in organizational performance from each technical practice studied. DORA is a Google Cloud research programme."
  - title: "Google developer documentation style guide"
    author: Google
    url: "https://developers.google.com/style"
    type: guide
    year: 2026
    note: "Google's style guide for technical documentation, covering voice and tone, punctuation, formatting, code samples and word choice. It calls itself guidelines rather than rules and puts a project's own style first."
  - title: "Software Documentation: The Practitioners' Perspective"
    author: Emad Aghajani, Csaba Nagy, Mario Linares-Vásquez, Laura Moreno, Gabriele Bavota, Michele Lanza and David C. Shepherd
    url: "https://www.inf.usi.ch/faculty/lanza/PUBS/P/Agha2020a.pdf"
    type: paper
    year: 2020
    note: "An ICSE 2020 paper reporting two surveys of 146 practitioners. The first rates 51 documentation issues, summarised from the authors' taxonomy of 162; the second asks which kinds of docs help with which tasks. Clarity was the issue rated important by the most respondents (88%)."
